# Guia de Contribuição

Obrigado por querer contribuir! Para garantir a qualidade do nosso projeto, siga as regras abaixo:

## Padrão de Branch
Crie branches a partir da `develop` utilizando o padrão:
- `feature/nome-da-funcionalidade`
- `bugfix/nome-do-erro`
- `docs/nome-do-documento`

## Padrão de Commits
Seus commits devem ser claros e em português, descrevendo o que foi alterado.

## Pull Requests (PR)
- Só abra um PR quando o código estiver devidamente testado localmente.
- O autor do PR deve preencher o checklist do template e solicitar revisão de no mínimo 1 colega.
- Você deve ser capaz de explicar cada linha do código durante a reunião de revisão síncrona.
